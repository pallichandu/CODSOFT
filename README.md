# 📝 To-Do List App

A simple command-line To-Do List application built with Python. It allows users to add, view, and delete tasks easily.

## 🚀 Features

- Add tasks
- View tasks
- Delete tasks
- Easy-to-use menu interface

## 🛠️ Technology

- Python 3

## 📚 Concepts Used

- Lists
- Loops
- Conditional Statements
- User Input Handling

## 🔮 Future Improvements

- Save tasks to a file
- Mark tasks as completed
- Add priorities and deadlines
- Create a GUI version

⭐ A beginner-friendly Python project for practicing basic programming concepts.
